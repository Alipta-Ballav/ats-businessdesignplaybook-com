# Phase 1: Resume workflow quality

Keep the first resume scan registration-free. Preserve the original report, edited text, in-progress bullet and undo history when the guest signs in. Import the original scan only once and retain the temporary copy if saving fails.

Add a clean, single-column A4 PDF alongside Word using the same presentation blocks. Embed fonts, wrap long text, avoid orphan headings and keep all text selectable. This is a clean ATS layout, not a reproduction of an uploaded graphical layout.

Reuse AI responses only for identical original text and supplied facts within the current editor session. Explicit regeneration always requests a fresh response. Show immediate factual checks while drafting. Do not change models, extraction, final score calculations or paid evaluation rules.

Guest handoff copies expire after 24 hours and are removed on successful account import. They are not general draft autosave or a “pick up where you left off” feature. Signed-in originals remain immutable; users save named versions explicitly.
