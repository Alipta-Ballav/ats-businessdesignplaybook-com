# ATS

FutureTalent AI evaluates product and UX design resumes against job requirements, design competencies, and ATS criteria.

Recruiters can create roles with must-have requirements and tune scoring for seniority, strictness, and skill weights. Candidates can compare resumes across eight design dimensions and ATS engines, review evidence-based reports, and apply suggested edits with undo controls. The app also supports saved resume progress, a bullet library, promotion audits, role teardowns, and calendar reminders.
